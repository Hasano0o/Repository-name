# Bandly Router Knowledge Base

قاعدة معرفة داخلية لتوثيق توافق الراوترات.

## قواعد العمل
- لا تعتبر أي معلومة مؤكدة دون مصدر أو اختبار موثق.
- افصل بين المعلومة المنقولة من مصدر والنتيجة المختبرة فعليًا.
- لا تحفظ كلمات مرور أو Cookies أو Tokens أو بيانات شخصية.
- لا تنفذ أوامر تغيير إعدادات الراوتر أثناء اختبارات القراءة.
- لا تعتمد ميزة قبل اختبارها ومراجعة أمانها.
- لا تعتبر نجاح موديل واحد دليلًا على دعم جميع موديلات الشركة.

## حالات التحقق
- DISCOVERED: معلومة مكتشفة ولم يتم التحقق منها.
- CODE_TESTED: نجح اختبار الكود على عينات محفوظة.
- DEVICE_TESTED: اختبرت الميزة على راوتر فعلي، مع توثيق الموديل والبرنامج الثابت.
- APPROVED: اجتازت المراجعة وأصبحت مؤهلة للدمج.

## الحد الأدنى لكل موديل
1. الموديل وإصدار البرنامج الثابت.
2. المصادر وتراخيصها.
3. واجهات API وحقول البيانات المعروفة.
4. الميزات المدعومة وغير المدعومة.
5. نتائج الاختبارات والمشاكل المعروفة.
6. سجل التغييرات وتاريخ التحقق.
